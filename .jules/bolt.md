## 2026-06-12 - [Concurrent Bootstrap Data Load]\n**Learning:** The bootstrap process sequentially loaded large independent root entities (portfolio, bookings, clients, staff, transactions, inventory) via await, which compounded database connection acquisition delay and overall latency. Additionally, dependent relations (channel mappings and icals) inside loops exhibited classic N+1 queries by emitting two round trips per nested iteration.\n**Action:** Bundle independent queries into a single Promise.all, and for dependencies, extract identifiers first (e.g. using flatMap) then batch fetch with the `in` operator within a Promise.all block. This pattern significantly minimizes database round trips and drastically improves initial app load time.
