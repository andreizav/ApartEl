## 2024-05-18 - Optimize Bootstrap Service Data Fetching
**Learning:** In standard application bootstrap APIs, fetching independent root collections (like bookings, clients, staff) via sequential `await` expressions acts as a hard performance barrier, compounding round-trip latency. Furthermore, looping over fetched associations to fetch secondary associations creates an N+1 query problem that scales linearly with the dataset size.
**Action:** Always wrap independent root-level Prisma fetches in a concurrent `Promise.all()` structure. Replace looping fetches for nested associations by mapping a unique ID array and using relational `where: { in: [] }` or deep relational traversal (`where: { unit: { group: { tenantId } } }`) to flatten nested requests into single bulk queries.
